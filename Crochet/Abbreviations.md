5. ==**sc**==: Single crochet, the standard crochet unknot. Although this applies to all crochet's I'm going to say it for this one only. You can use sc-*name* to denote a position to do the crochet in. 
6. ==**dc**==: Double Crochet
7. ==**tc**==: Treble Crochet
8. ==**ss**== or ==**sl st**==: Slip Stitch.
9. ==**ch**==: Chain, consecutive stitches. We can say ch-$n$ to specify a count, e.g. ch-5 for 5 consecutive stitches.
10. ==**sp**==: space, skip a stitch in the chain you're working in, leaving a space.
11. ==**ch-**==$x$: The $x$ can be replaced with any stitch e.g. ch-ss is a chain of slip stitches, or ==**ch-sp**== which is a chain space, leave multiple spaces
12. ==**dtr, trtr, ...**==: Double Treble and Treble Treble, and so on and so forth respectively.
13. ==**inc**==: Increase
14. ==**dec**==: Decrease
15. ==**sm**==: Stitch marker. You can assign a name and use it as a reference for this stitch for more complicated patterns. Personal notation could be sm-$x$.
16. ==**rnd**==: Round of crochet's to perform, thought of as a list of instructions to follow. This is done like $\text{rnd } 1:$ 
17. ==**rep**==: Repeat instructions in a round. This is done like $\text{rep }x$.
18. ==**mr**==: Magic ring, this is done by doing:
	* $1$ **sc**
	* **pm**-*magic ring*
	* $6$ **sc** in *magic ring*
	* **ss**
19. ==*start*==: constant which denotes the first stitch in the project.
20. ==*rnd-start*==: constant which denotes the first stitch in the round.
