A set $B$ is balanced if every $\alpha B \in B$ for every $\alpha \in \Phi$ such that $|\alpha| \leq 1$.

1. A balanced set $B$ contains all points between $0$ and $x \in B$.
2. All balanced sets contain $0$, this can be checked by grabbing two distinct points $p, q \in B$, when $\alpha=0$ then $\alpha p = \alpha q = 0$, meaning that the intersection between two distinct points in a balanced set will never be $\emptyset$.
3. For any distinct points $p, q$ in balanced sets that are collinear to one another the intersection will equal the set of the point with the shortest distance to the origin. since the set is the same as a balanced point in a set, then the intersection remains balanced.
4. The union of a balanced set is a balanced set because for each element $x \in B$ there is $\alpha x \in B$.
