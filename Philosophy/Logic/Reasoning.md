# Deductive Reasoning
Is a type of reasoning in which given [[Rhetoric#^fb57f7|truthful]] premises provides certain conclusions.
## Syllogism
A form of reasoning in which a conclusion is drawn (whether validly or not) from two given or assumed [[Rhetoric#Vocabulary|propositions]], each of which shares a term with the conclusion, and shares a common or middle term not present in the conclusion. It is a type of ==**deductive reasoning**== (Based on inference of particular instances from a general law).
### Example
1. *Proposition 1*: <mark style="background: #FF5582A6;">All humans</mark> <mark style="background: #ADCCFFA6;">have a brain</mark>
2. *Proposition 2*: <mark style="background: #FF5582A6;">Fulano</mark> <mark style="background: #ADCCFFA6;">is a human</mark>; therefore Fulano has a brain.
If we wanted to define this mathematically we can say that if the subject $A \subseteq B$ and the subject $C \subseteq A$ then $C \subseteq B$. That is to say $C \subseteq A \subseteq B$.
