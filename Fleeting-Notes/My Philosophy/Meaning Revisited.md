# The Definition
A definition $D$ is an ordered pair $(a,b)$ such that it is 
* [[Relations#Reflexive|reflexive]]
* [[Relations#Symmetric|symmetric]]
Although one would think it needs to be transitive, it is not necessary.
# The Context
Given a set $X$ of semiotic signs, the context $\mathcal{C}$ relates semiotic signs with one another. It is a collection of definitions $D$, fulfilling the order relations. An example of a subset of the context, would be: $$\{(\text{circle},\text{all points within a distance }r)\}\subset\mathcal{C}$$
So too does it contain the definitions of all words in the language. We can view the relation as such: $$D=(a,b)\in\mathcal{C},\text{ s.t. }a,b\in X$$
