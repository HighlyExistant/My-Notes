# Definition
All communication is done via a ==**means**== $\mathcal{M}=(\mathcal{S}, f)$. Means are equipped with a ==**set of symbols**== $\mathcal{S}$, with which we use to communicate within that means, as well as an ==**action that produces a symbol of another set**== denoted as $f$. Every individual person however is guided by a ==**context**== $\mathcal{C}$ which denotes the definitions of words. These definitions offer [[Relations#Equivalence|equivalence relations]] between sets of symbols in the same or other means.
## Example
Let $\mathcal{M_S}=(\mathcal{S}, s)$ be the means of speech and let $\mathcal{M_G}=(\mathcal{G}, g)$ be the means of geometric images generated through our eyes and mind. The context $\mathcal{C}=\mathcal{M_S}/\mathcal{M_G}$ is composed of the various equivalence relations we have composed between these. If we were to grab an element of the set $\mathcal{M_S}$ such as $\text{circle}\in\mathcal{M_S}$ it would be equivalent with ${\Huge{\circ}}\in\mathcal{M_G}$. We could write this out as: $${\Huge\circ}\equiv \text{circle}$$The action $s$ returns a subset of symbols which are all equivalent to the base symbol, so if we were to write out $s_{\mathcal{G}}(\text{circle})=\{{\Huge\circ}, {\large\circlearrowleft}, {\large\circlearrowright}, ...\}$. Of course the number of symbols which could exist can be infinite, as we can produce as many transformations to the circle as we want. If we were to do the inverse however it would come out to be $g_{\mathcal{S}}(\circ)=\{\text{circle}, \text{ring}, \text{halo}, ...\}$, and depending on how many words exist in the context (within the English language in this case) to provide a definition for said word, that's how many there are. Of course these actions outputs are dependent on the context $\mathcal{C}$, which is why ==**they are not pure functions**==.
# Sub-Means
Of course, there are as many means, as there are ways of communicating, as well as sub-means within those means. For example, there is *the set of all images we can see and or imagine*, which we can denote as $\mathcal{M_I}$. In our past example, we used $\mathcal{M_G}$ as the means of all geometric images. We can of course say that $\mathcal{G}$ is a subset of $\mathcal{I}\in\mathcal{M_I}$ which can be written as: $$\mathcal{I}\subseteq\mathcal{G}$$They are equal to one another since every image we can conjure up is a geometric image in some way. That said if we take the subset of only hypercubes, then we can achieve an actual subset: $$\mathcal{G_\square}\subset\mathcal{G}$$A sub-means, can then be defined as a means where the set of symbols is a subset of another means set of symbols.

## Direct Relation
Given any means $\mathcal{M}$, an element of that set $c\in\mathcal{M}$ which has a definition such that $c$ is a binary operator which provides an equivalence relation between any two elements. That element $c$ has the same power as $=$.
