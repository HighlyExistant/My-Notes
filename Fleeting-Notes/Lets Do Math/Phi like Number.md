The following document will make use of the following equation that I just made up: $$\varphi^{x}+1=\varphi^{x+1}$$With the sole purpose of just having fun and seeing where this will take us. This is taking inspiration of course that: $$\phi+1=\phi^2$$except that I want to make my own logic, wherein the power does not matter. We will define a new set of numbers called $\Phi$ which contains our **phi like** numbers. $$\Phi=\{a+b\varphi|a,b\in\mathbb{R},\varphi^x+1=\varphi^{x+1}\}$$
# Properties
# Identities
We can quickly turn an equation like $\varphi^{x}+1=\varphi^{x+1}$ into: $$\varphi^{x}=\varphi^{x+1}-1$$which means that any whole number which subtracts our phi like numbers will lower its power by one, similar to how summing a whole number would increase its power. We can also turn this into a zero identity where: $$\varphi^{x}+1-\varphi^{x+1}=0$$We can also reach an identity for what summing powers would look like by simply multiplying the original equation by $\varphi$: $$\begin{matrix}\varphi^{x}+1=\varphi^{x+1}\\\Rightarrow (\varphi^{x}+1)\varphi=(\varphi^{x+1})\varphi\\\Rightarrow\varphi^{x+1}+\varphi=\varphi^{x+2}\\\Rightarrow\varphi^{x}+\varphi=\varphi^x+1\\\Rightarrow\varphi=1\end{matrix}$$

This is weird however since $\varphi=1$. If this is true, then $$\varphi^x(1)=\varphi^{x+1}=\varphi^x+1$$which would then mean that $\varphi\to\infty$, as well as that $\varphi^x=\varphi^y$. ==**We can then see how this little game I made falls apart :(**==.
