# Axiom of Composition
1. Given action $A$ and action $B$ such that $A, B$ are considered **bad**, then given some arbitrary measure $\mu$ that calculates an actions "badness" $\mu({A}) \leq \mu({B}) \le \mu({A\cup B})$.
Therefore if you want to prove that $A$ is worse than $B$, one way of doing it is by showing that $B\subset A$.
