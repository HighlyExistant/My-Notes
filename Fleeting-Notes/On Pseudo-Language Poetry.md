# Pseudo-Language Haiku
A Haiku is a 3 line, 5-7-5 syllable poem. If we were to write a pseudo-language haiku poem, we could say its:

let $\alpha$ be an element of stressed syllables, let $\iota$ be an element of unstressed syllables. if we composed a poem with these requirements (either stressed or unstressed syllable) there would be around $2^{(5+7+5)}=131072$ different haiku poems composed of this equivalence relation. Lets grab a random element from this equivalence relation and create a poem. Grabbing from my random number generator I got $116538\in[0, 131072]\subset\mathbb{N}_0$. This would correspond to the binary number: $0b11100011100111010$. Translating this with the isomorphism $0\to\iota, 1\to\alpha$ and going from least to most significant we get the haiku: $$\begin{matrix}\iota\alpha\iota\alpha\alpha\\\alpha\iota\iota\alpha\alpha\alpha\iota \\\iota\iota\alpha\alpha\alpha\end{matrix}$$
Now frankly I wanted to write a poem using these rules, but I got stumped near the beggining. Specifically at $\alpha \alpha$ the final 2 syllables of the first verse. Finding a word that has 2 consecutive stressed syllables in english is hard. And considering that there are even words that have 3 consecutive stressed syllables, it becomes even harder. Good thing we're dealing with pseudo language however. The meaning here for me does not matter. I'll just make the poem have the unstressed syllables 'dou', 'fen', 'ple' 'moon' and the stressed syllables 'fa' 'pa' 'dee' and 'gee'. This gives us the pl-poem:
	*dou* **'fa** *fen* **'pa** **'dee**
	**'gee** *ple* *moon* **'fa** **'pa** **'dee** *'dou*
	*fen* *ple* **'gee** **'fa** **'pa**.
