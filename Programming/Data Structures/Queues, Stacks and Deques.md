# Queues
Is a First In First Out (FIFO) data structure, meaning that values are obtained in the order they were inserted. These are used mainly when the data you want to use has to come at a particular order. 
# Stacks
Is a First in Last Out (FILO) data structure, meaning that values are obtained in order of the most recently added values. These are useful for recursive data structures, as they can create 'frames' of variables to be used within each iteration of a recursion.
# Double Ended Queue (Deque)
Is both a FIFO and FILO data structure. 
# Cyclic Buffer
Also known as a circular queue or ring buffer. This maps an array of values unto a modulus space of indices. This is useful for implementing things like [[Queues, Stacks and Deques#Queues|Queues]], and certain allocators.
