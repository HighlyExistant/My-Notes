# How does time work in a CPU
Computers have a quartz ticker with constant energy which produces a tick at constant frequency, which that tries to keep the time ticking, to keep the actual time, regardless of internet. The Raspberry PI doesn't have this, and therefore when it connects to the internet it will run the Network Time Protocol (NTP) to receive the actual time. 

# Strongly Typed vs Weakly Typed
In a strongly typed language, you cannot redefine types, while in a weakly typed language, you can redefine a variable to a different type. C++ for example, is a strongly typed language, while python is weakly typed.
# When learning a new Language
1. Learn the rules for defining variables.
2. Learn the basic keywords in the programming language.
