Written as $$\sum_{i=1}^nx_i$$where $n\in\mathbb{N}$ is the total count of values to be summed, $i$ is an index and $x_i$ is the indexed value. the summation above would be equivalent to: $$\sum_{i=1}^nf(x_i)=f(x_1)+f(x_2)+...+f(x_n)$$
# Rules
## Sum and Difference Rules
$$\sum_{i=1}^n(x_i\pm y_i)=\sum_{i=1}^n{x_i} \pm  \sum_{i=1}^n{y_i}$$
## Constant Value Rule
$$\sum_{i=1}^n{c}=cn$$where $c$ is any constant.
## Constant Multiple Rule
$$\sum_{i=1}^n{cx_i}=c\sum_{i=1}^n{x_i}$$where $c$ is any constant.
# Summation to Formula with Falling Powers
We can convert summations into formulas using integrals, but we must replace powers with [[Factorization#Falling and Rising Factorials|falling powers]]. The way we can convert sums to formulas is via: $$\sum_{k=1}^nk^{\underline{n}}=\frac{1}{n+1}k^{\underline{n+1}}$$
We can see this in gauss summation: $$\sum_{k=1}^n{k}=\frac{n(n+1)}{2}$$
