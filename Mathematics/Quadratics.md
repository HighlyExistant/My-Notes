# Finding Zeroes
## Factorization
The first way of quickly finding zeroes is through factorization. If we can turn a function into the form $$(x-c_0)(x-c_1)$$we can quickly find all the zeroes using the product of zero rule, making the location of the zeroes equal to $x=c_0,c_1$. A few techniques to do this is by remembering that $$(x+c_0)(x+c_1)=x^2+(c_0+c_1)x+c_0c_1$$which means we just have to find two numbers that add up to $b$ and multiply to $c$.
### Identities for Factorization
We can also use identities that have already been proven to quickly fill out special cases:
1. Difference of Squares: $a^2-b^2=(a-b)(a+b)$
2. Perfect Squares: $a^2+2ab+b^2=(a+b)^2$
3. Perfect Squares: $a^2-2ab+b^2=(a-b)^2$
## Quadratic Formula
We can also find zeroes by using our ultimate weapon, the quadratic formula: $$\frac{-b \pm\sqrt{b^2-4ac}}{2a}$$
## PQ Formula
Although only for monic quadratics, if we simplify the expression $$ax^2+bx+c$$ by dividing by $a$: $$\frac{ax^2+bx+c}{a}=x^2+\frac{b}{a}x+\frac{c}{a}$$then we can use the $pq$ formula, for $x^2+px+q$: $$-\frac{p}{2}\pm\sqrt{(\frac{p}{2})^2+q}$$Which is simply the quadratic formula, where $a=1$.
