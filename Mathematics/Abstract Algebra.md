#### Archimedean property
This property states that given two positive numbers $x, y$ there exists an integer $n$ such that $nx>y$. It basically means that sets of numbers such as natural numbers, are not bounded above. For example, given $x=1$ and $y=4$, then there exists a number $n$ which in this case would be any number $n>4$ where $nx>y$.
#### Infimum of a set
For any non empty set $A$ there exists $a \in A$ such that $a$ is lesser than or equal to each element of the set $A$.
#### Supremum of a set
For any non empty set $A$ there exists $a \in A$ such that $a$ is greater than or equal to each element of the set $A$. This can be denoted as $\text{sup}$ for supremum.
