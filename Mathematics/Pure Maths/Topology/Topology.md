A topology originally comes from a generalization of the real number line. It is the basis of all mathematical spaces.
# Definition
The following definition is from [TOPOLOGY. SECOND EDITION. JAMES R. MUNKRES](https://eclass.uoa.gr/modules/document/file.php/MATH707/James%20R.%20Munkres%20Topology%20%20Prentice%20Hall%2C%20Incorporated%2C%202000%20by%20James%20R.%20Munkres%20%28z-lib.org%29.pdf):

A ***topology*** on a set $X$ is a collection $\Large{\tau}$ of subsets of $X$ having the following properties:
1. $\emptyset$ and $X$ are in $\Large{\tau}$
2. The union of the elements of any subcollection of $\Large{\tau}$ is in $\Large{\tau}$.
3. The intersection of the elements of any finite subcollection of $\Large{\tau}$ is in $\Large{\tau}$.
A set $X$ for which a topology $\Large{\tau}$ has been specified is called a topological space. Such a space is denoted by an ordered pair $(X, {\Large{\tau}})$.
### Useful Lemmas
1. The union of open sets in ${\Large\tau}$, is an open set.
2. The intersection of open sets in ${\Large\tau}$, is an open set.
## The Discrete Topology
For any set $X$ its [[Set Theory#Power Set|power set]] $\mathcal{P}(X)$ is a topology ${\Large\tau}_d$.
## The Indiscrete or Trivial Topology
For any set $X$ the most basic topology it can have is $${\Large\tau}_i=\{\emptyset, X\}$$
## The Finite Complement Topology
Given a set $X$, let ${\Large\tau}_f$ be the collection of all $U\subset X$ such that $X\setminus U$ is either finite or all of $X$. ${\Large\tau}_f$ is then the finite complement topology. $\emptyset$ and $X$ is in ${\Large\tau}_f$ since $X\setminus X=\emptyset$ and $X\setminus\emptyset=X$. Written symbolically: $${\Large\tau}_f=\{A\subseteq X|A=\emptyset\text{ or }X\setminus A\text{ is finite}\}$$
## Open Sets
An open set is supposed to be the generalization of an open interval on the real number line $(a,b)$. Here we say that a subset of $X$ is an open set if it is an element of $\Large\tau$. We write this as: $$U\in {\Large\tau}, U\subseteq X$$
## Finer and Coarser Topologies
The terminology of finer and coarser, according to James R. Munkres, comes from thinking of topologies as gravel and the pebbles as well as their unions as open sets. It would seem then that smaller sets contain larger pebbles, while smashing pebbles into smaller ones makes it into a larger topology. We say then that large topologies are finer and smaller topologies are coarser. If we were to write this mathematically we would say that, given two topologies ${\Large\tau}$ and ${\Large\tau}'$
1. if ${\Large\tau}\subset {\Large\tau}'$  then ${\Large\tau}'$ is ==**strictly finer**== and ${\Large\tau}$ is ==**strictly coarser**==. The term ==**strictly**== is used when they are proper subsets. We can think of this kind of as finer being larger and coarser being lesser.
2. We say that ${\Large\tau}'$ is ==**finer**== than ${\Large\tau}$ if it has more open sets or equal open sets than that of ${\Large\tau}$. While the book does warn about the use of the words stronger and weaker, the [following course note](https://drive.google.com/file/d/1DHNMXlp7y4S4Yz_cPwd3drLyBQi-J1mp/view) use them in such a way where "stronger" replaces "finer" and "weaker" replaces "coarser".
3. If either ${\Large\tau}'\subset {\Large\tau}$ or ${\Large\tau}'\supset {\Large\tau}$ then ${\Large\tau}$ is ==**comparable**==.
# Basis for a Topology
These function as generalizations of the [[Linear Algebra#Basis Vectors|basis]] in vector spaces

Given a set $X$, a ==**basis**== for a topology is a collection $\mathscr{B}$ of subsets of $X$ (called ==**basis elements**==) such that:
1. For each $x\in X$, there is at least one basis element $B$ containing $x$.
2. If $x$ belongs to the intersection of two basis elements $B_1$ and $B_2$, then there is a basis element $B_3$ containing $x$ such that $B_3\subseteq B_1 \cap B_2$.
If $\mathscr{B}$ satisfies those conditions, we can define a topology ${\Large\tau}$ generated by $\mathscr{B}$, as: 
A subset $U\subset X$ is in ${\Large\tau}$ if for each $x\in U$ there is $B\in\mathscr{B}$ such that $x\in B$ and $B\subset U$. This also means each basis element is in ${\Large\tau}$. Effectively what this is saying is that all the unions of the basis elements are going to be in the topology as well. This also includes $\emptyset$ as the union of an empty collection of sets of $X$ is $\emptyset$.
## Properties
2. $\mathscr{B}\subseteq{\Large\tau}$
3. Every element in ${\Large\tau}$ can be expressed as a union of elements in $\mathscr{B}$.
### Example 1
Given a set $$X=\{a, b, c, d, e, f\}$$we can construct a topology using a basis: $$\mathscr{B}=\{\{a, b, c\},\{d,e,f\}\}$$
This basis satisfies both properties. We can now go on to create our topology. Firstly we know all our basis elements are in ${\Large\tau}$ as well as $\emptyset$ and $X$ so we can add those. In fact those are all the elements in our topology, as there are no more proper subsets we can create from $X$. Our topology ends up being: $${\Large\tau}=\{\emptyset, X, \{a, b,c\}, \{d, e, f\}\}$$
If we instead had the basis: $$\mathscr{B}=\{\{a, b\}, \{c, d\}, \{e,f\}\}$$then we would have the 3 basis sets, $\emptyset$ and $X$ as well as now, their unions: $\{a, b, c, d\}, \{a, b, e, f\}, \{c, d, e, f\}$. This would give us the topology: $${\Large\tau}=\{\emptyset,X, \{a, b\}, \{c, d\}, \{e,f\},\{a, b, c, d\}, \{a, b, e, f\}, \{c, d, e, f\}\}$$
## Basis for Topologies on $\mathbb{R}$
There are 3 basis for topologies on $\mathbb{R}$, which are the standard topology, as well as the lower and upper limit topologies.
### The Standard Topology
The way we construct it is by grabbing the set of all open intervals on $\mathbb{R}$ and making that a basis: $$\mathscr{B}=\{(a,b)|a,b\in\mathbb{R},a<b\}\cup\{(-\infty, b)|b\in\mathbb{R}\}\cup\{(a,\infty)|a\in\mathbb{R}\}$$We don't need to do all of this however. The set of all open intervals is enough to make the standard topology: $$\mathscr{B}=\{(a,b)|a,b\in\mathbb{R}, a<b\}$$
A countable version of this is using the rational numbers instead of the reals: $$\mathscr{B}=\{(a,b)|a,b\in\mathbb{Q},a<b\}$$
### The Lower Limit Topology
The set of all half open bounded intervals is the lower limit topology: $$\mathscr{B}_\ell=\{[a,b)|a,b\in\mathbb{R},a<b\}$$
### The Upper Limit Topology
Is very similar to the lower limit topology: $$\mathscr{B}_u=\{(a,b]|a,b\in\mathbb{R},a<b\}$$
###  The K Topology
This is similar to the standard topology, except it also includes the set of all $(a, b)\setminus K$ such that $K=\{\frac{1}{n}|n\in\mathbb{N}\}$: $$B_K=\{(a,b)|a,b\in\mathbb{R}, a<b\}\cup\{(a,b)\setminus K|a,b\in\mathbb{R},a<b\}$$
# Subbasis for a Topology
The definition of a subbasis $\mathcal{S}$ is similar to that of a basis but with fewer restrictions. A subbasis of a topology ${\Large\tau}$ on $X$ is a collection of subsets of $X$ whose union is $X$. To generate a topology using a subbasis, it is simply all the unions of finite intersections of $\mathcal{S}$. We can see then that the basis formed by the subbasis is just all the finite intersections of $\mathcal{S}$.
### Example 1
Given a set $X=\{a, b, c, d\}$ and a subbasis $\mathcal{S}=\{\{a, b\}, \{c, d\}\}$ the generated basis would be: $$\mathscr{B}=\{\emptyset, \{a,b\}, \{c,d\}\}$$and its topology is: $${\Large\tau}=\{\emptyset, X, \{a, b\}, \{c, d\}\}$$
Given instead a subbasis $\mathcal{S}=\{\{a, b\}, \{b, c, d\}\}$ then its basis is: $$\mathscr{B}=\{\emptyset, \{a, b\}, \{b, c, d\}, \{b\}\}$$and its topology is: $${\Large\tau}=\{\emptyset, X, \{a, b\}, \{b,c,d\}, \{b\}\}$$
# The Order Topology
Given a [[Relations#Strict Order|strict order]] relation $<$ (Munkres calls it a ==**simple order**==) which satisfies:
1. [[Relations#Comparable|Comparability]]
2. [[Relations#Antireflexive|Antireflexivity]]
3. [[Relations#Transitive|Transitivity]]
We can generate an order topology as follows. Let $X$ be a set with a simple order relation $<$. The following sets are intervals in $X$:
4. [[Set Theory#Open Intervals|Open Intervals]]
5. [[Set Theory#Closed Intervals|Closed Intervals]]
6. [[Set Theory#Half Open Intervals|Half Open Intervals]]
# The Dictionary Topology
Given an order on some topology $\mathbb{R}^2$ we define a strict order relation $<$ such that $(a, b),(c,d)\in\mathbb{R^2}$ satisfies:
1. $a<c$ when $a\neq c$
2. $b<d$ when $a=c$
This has as a basis, all open intervals of the form $(a\times b, c \times d)$ such that 
3. $a< c$ 
4. $a=c$ and $b < d$
So we can represent it as: $$\mathscr{B}=\{(a\times b, c \times d)|a < c\}\cup \{(a\times b, c \times d)|a = c\text{ and } b < d\}$$
## Definition
Let $X$ be a set with a simple order relation, and assume $|X|>1$. Let $\mathscr{B}$ be the collection of:
1. All [[Set Theory#Open Intervals|Open Intervals]] $(a,b)$
2. All [[Set Theory#Half Open Intervals|Half Open Intervals]] $[a_0,b)$ such that $a_0$ is the least element of $X$ if one exists, 
3. All Half Open Intervals $(a,b_0]$ such that $b_0$ is the greatest element if one exists.

The collection $\mathscr{B}$ is a basis for the ==**order topology**==. If $X$ has no smallest element, then there are no sets of type $[a_0,b)$ and if it has no largest, then there are no sets of type $(a,b_0]$. This means that 
### Properties
1.  $a_0\in [a_0,b), \forall b\in X$
2.  $b_0\in (a,b_0], \forall a\in X$.
## Rays
If $X$ is an ordered set and $a\in X$ then there are 4 subsets of $X$ called rays. These are: 
### Open Rays
These are open sets in the order topology.
$$(a,\infty)=\{x| x> a\}$$ $$(-\infty,a)=\{x| x< a\}$$
### Closed Rays
$$[a, \infty)=\{x| x \geq a\}$$ $$(-\infty,a]=\{x| x \leq a\}$$ 
### Properties
* If the largest element in $X$ is $b_0$ then $(a,\infty)$ would be the basis element $(a, b_0]$. If no such element exists, then it is the union of all basis elements of the form $(a,x)$ where $x>a$. The converse, where $(-\infty, a)$ is also true.
* The open rays of the order topology form a subbasis for the order topology on $X$. This is due in part because a open set $(a,b)$ can be formed as $(a,b)=(a,\infty)\cap(-\infty, b)$.
# Product Topology
Given two topological spaces $X$ and $Y$, you can generate a topology for their [[Set Theory#Cartesian Product|cartesian product]] as follows:
## Definition
Let $X$ and $Y$ be topological spaces. The product topology on $X\times Y$ is the topology having as basis the collection $\mathscr{B}$ of all sets of the form $U\times V$, where $U\subseteq X$ and $V\subseteq Y$.

This satisfies the conditions of a topology since:
1. $X\times Y$ is in the topology when $U=X, V=Y$.
2. The intersection of any two basis elements is another basis element
3. The generated topology is composed of all the unions of the elements.
excerpt
### Basis for a Product Topology
The following is a direct excerpt.
If $\mathscr{B}$ is a basis for the topology $X$ and $\mathscr{C}$ is a basis for topology $Y$, then the collection $$\mathscr{D}=\{B\times C|B\in\mathscr{B}, C\in\mathscr{C}\}$$is a basis for the topology $X\times Y$.
### Subbasis for a Product Topology
The way Munkres does this is by defining two [[Functions#Surjective|surjective]] [[Functions#Projections|projection functions]]: $\pi_1: X\times Y\to X$ and $\pi_2:X\times Y\to Y$, such that: $$\pi_1(x,y)=x$$and $$\pi_2(x,y)=y$$Given a subsets $U\subseteq X$ and $V\subseteq Y$, the [[Functions#Preimage (Inverse Image)|preimage]] of these functions is then: $$\pi_2^{-1}(V)\to X\times V$$and $$\pi_1^{-1}(U)\to U\times Y$$
Which then leads to the theorem: $$\mathcal{S}=\{\pi_1^{-1}(U)|U \text{ open in } X\}\cup\{\pi_2^{-1}(V)|V\text{ open in } Y\}$$
is a subbasis for the product topology on $X\times Y$.
## **Generalized Product Topology**
You will notice that the generalized version of the product topology is very similar to the one we did with only 2 elements.
### Box Topology Basis
Let $\{X_\alpha\}_{\alpha\in J}$ be an indexed family of topological spaces with product space $$\prod_{\alpha\in J}{X_\alpha}$$with the topology generated by the basis $$\mathscr{B}=\{\prod_{\alpha\in J}U_\alpha : U_\alpha \text{ open in }X_\alpha\}$$Which would be the product space with box topology.  
### Product Topology Subbasis
Let $$\pi_\beta: \prod_{\alpha\in J} X_\alpha \to X_\beta$$Be the surjective projection function which takes an element of the product topology to its $\beta$th coordinate. It's preimage will behave similarly to how it would behave in the subbasis of a product topology, and we would be left with $$\mathcal{S_\beta}=\{\pi_\beta^{-1}(U_\beta)|U_\beta \text{ open in } X_\beta\}$$Then $$\mathcal{S}=\bigcup_{\beta\in J}{S_\beta}$$would be the subbasis, and the topology generated by these would be the product space.

# Subspace Topology
Given a set $X$ with topology ${\Large\tau}$, if $Y\subseteq X$, then $${\Large\tau}_Y=\{Y\cap U|U\in {\Large\tau}\}$$
is a topology on $Y$, known as a subspace topology, and $Y$ is a subspace of $X$.
## Basis of a Subspace
Given a set $X$ with a basis ${\mathscr{B}}$, if $Y\subseteq X$, then Similarly we can denote: $$\mathscr{B}_Y=\{Y\cap B|B\in \mathscr{B}\}$$
## Examples
### Example 1: Subspace of the Standard Topology on the real numbers
Given a set $X=\mathbb{R}$ with a standard topology (and or an order topology) $\mathscr{B}=\{(a,b)|a,b\in\mathbb{R}, a<b\}$, and $Y=[0,1]$ and the subspace topology. Then the basis of said subspace topology would be $\mathscr{B}_Y$ composed of all sets of the form $(a,b)\cap Y$. This subspace topology therefore contains:
1. All sets $(a,b)\subset Y$
2. $[0, b),\text{ s.t. }b\in Y$
3. $(a, 1],\text{ s.t. }a\in Y$
4. $Y$ and $\emptyset$.
Important to note that $[0, b)$ and $(a,1]$ are not open sets of $X$.
### Example 2: Anomaly of Noncontinuous Sets
Let $Y=[0,1)\cup \{2\}\subset \mathbb{R}$. In the subspace topology on $Y$, the one point set $\{2\}$ is open, because it is the intersection of $U\cap Y$ where $U=(\frac{3}{5}, \frac{5}{2})$.  However it is not open in the order topology, since any set that contains $2$ needs to be of the form $x\in Y\text{ and } a < x \leq 2$ for some $a\in Y$, and we can see that the set does not necessarily contain points of $Y$ less than $2$.
## Convex Subsets
Given an ordered set $X$, a subset $Y\subseteq X$ is ==**convex**== in $X$ if for each pair of points $a,b\in Y,a<b$, the entire interval $(a,b)$ of points of $X$ lies in $Y$. 
### Convexity of Rays and Intervals
Given that a ray by definition includes all points between $a$ and $\infty$ as either a lower or upper bound, rays accomplish being convex. Equally so, intervals, given that they include all points between $a$ and $b$ are also convex. This means that all rays and intervals in $X$ are convex.
# Closed Sets and Limit Points
## Closed Sets
A subset $A$ of a topological space $X$ is said to be closed if the set $X\setminus A$ is open. Written differently, if $A$ is closed, then $A^C$ is open.
### Example 1: Run of the mill closed set
$[a,b]\subset\mathbb{R}$ is closed because its [[Set Theory#Complements|complement]]: $$\mathbb{R}\setminus[a,b]=(-\infty, a)\cup(b,\infty)$$is open.
### Example 2: Closed sets on 2 dimensions
Given a plane $\mathbb{R}^2$, the set $$\{x\times y|x\geq 0, y\geq 0\}$$is closed, because its complement is the union of the sets: $$(\infty,0)\times\mathbb{R}\text{ and }\mathbb{R}\times(-\infty, 0)$$and the product of open sets of $\mathbb{R}$ is open in $\mathbb{R}^2$.
### Example 4: Discrete Topology Case
in the discrete topology ${\Large\tau}=\mathcal{P}(X)$, every set is both open and closed.
### Example 5: Discrete Topology Case
Given a subset of $\mathbb{R}$$$Y=[0,1]\cup(2,3)$$we can see then that $[0,1]$ is open on $Y$ since it is the intersection of $(-\frac{1}{2},\frac{3}{2})$ and $Y$. Similarly $(2,3)$ is open in both $Y$ and $\mathbb{R}$. Both of these sets are also closed, since they are complements of each other.
## On Openness and Closedness
A set can therefore be 
1. Open
2. Closed
3. Both
4. Neither
## Theorems
### General Theorem of Closed Sets
1. $\emptyset$ and $X$ are closed, since they are complements of each other.
2. Arbitrary intersections of closed sets are closed
3. Finite unions of closed sets are closed.
### Closed Sets on Subspaces
Let $Y$ be a subspace of $X$. Then a set $A$ is closed in $Y$ if and only if it equals the intersection of a closed set of $X$ with $Y$.

## Theorems
### Theorem on Inherited Closedness
Let $Y\subset X$. If $A$ is closed on $Y$ and $Y$ is closed in $X$, then $A$ is closed in $X$. 
## Closure and Interior
### Interior of a Set
Given a subset $A$ of a set $X$, the interior of the set $A$ is the union of all open sets ==**_in_**== $A$. Due to the union of arbitrary open sets being open, the interior of a set is also open. This is usually denoted as $$\text{Int}(A)$$If $A$ is open, then $$\text{Int}(A)=A$$
### Closure of a Set
Given a subset $A$ of a set $X$, the closure of the set $A$ is the intersection of all closed sets ==**_containing_**== $A$. Due to the intersection of arbitrary closed sets being closed, the closure of a set is also closed. These are usually denoted as $$\text{Cl}(A)=\overline{A}$$Some I've seen denote it as, given a set $X$ with topology ${\Large\tau}$: $$\text{cl}_{(X, {\Large\tau})}{(A)}$$
The ordering of inclusion in the sets is: $$\text{Int}(A)\subseteq A\subseteq \overline{A}$$
If $A$ is closed, then $$A=\overline{A}$$
## Neighborhoods
An open set $U\subset X$ is a neighborhood of $x\in X$ if $x\in U$. This is a way of simplifying the statement "$U$ is an open set containing $x$"
## Theorems for Closures of Subspaces
### Theorem for Subspace Closures
Let $Y\subset X$ and $A\subset Y$. Let $\overline{A}$ be the closure of $A$ in $X$. Then the closure of $A$ in $Y$ is $\overline{A}\cap Y$. 
### Theorem for identifying elements in Closures
Let $A\subset X$, then:
1. $x\in\overline{A}\Leftrightarrow\forall U\in{\Large\tau}\text{ s.t. } x\in U,A\cap U\neq \emptyset$. If we wanted to simplify this, we could say that $x\in\overline{A}$ if every neighborhood of $x$ intersects $A$.
2. Supposing ${\Large\tau}$ of $X$ is given by a basis, then $x\in\overline{A}\Leftrightarrow \forall B\in\mathscr{B}, \text{ s.t. }x\in B, B\cap A\neq\emptyset$
#### Examples
1. If $A\subset \mathbb{R}=(0,1]$ then $\overline{A}=[0,1]$, this is because every open interval near $0$ contain $0$.
2. If $C\subset\mathbb{R}=(1,2)\cup\{0\}$ then its closure is $\overline{C}=[1,2]\cup\{0\}$. This is due to every open set containing $0$ intersecting $C$. Consider all sets of the form $(-a,b), a,b\in\mathbb{R},a<b$. All these sets contain $0$. We don't include values next to $0$ as you can think of an interval that does not include $0$, such as any set of the form $(a,0)$ or $(0,b)$. That said we include $1$ and $2$ since all sets that include numbers infinitesimally to the left of $1$ which include $1$ and right of $2$ which include $2$, are in the set. Think such sets as $(c,d), \text{ s.t. } c<a<d$ or $(c,d), \text{ s.t. }c<b<d$, you can see that for each, there needs to be an existent element $c$ or $d$ which is in the set and is in the neighborhood of either $a$ or $b$.
## Limit Points
Also known as cluster points or points of accumulation. If $A\subset X$ and $x\in X$, then $x$ is a limit point of $A$ if every neighborhood of $x$ intersects $A$ in some point other than $x$ itself. Expressed differently:

$x$ is a limit point of $A$ if $$x\in\text{Cl}(A\setminus\{x\})$$
### Theorems
Let $A$ be a subset of $X$, and $A'$ were all the limit points of $A$, then: $$\overline{A}=A\cup A'$$
### Corollaries
Where $A'$ is all limit points of $A$.
$$A\text{ is closed}\Leftrightarrow A'\subset A$$
## Convergence on a Sequence
Given a topological space $(X, {\Large\tau})$ a sequence $x_n$ converges to a point $x\in X$ if:
$$U\in{\Large\tau}\text{ s.t. }x\in U, \exists N\in\mathbb{N}\text{ s.t. } \forall n\geq N\Rightarrow x_n\in U$$

## Hausdorff Spaces
Given a set $X$ equipped with a topology ${\Large\tau}$, it is considered Hausdorff if for any distinct pair of points $x_1,x_2\in X$ there exists neighborhoods $U_1, U_2$ of $x_1,x_2$ respectively, such that they are [[Set Theory#Disjoint Sets|disjoint]]. Written symbolically: $$X\text{ is Hausdorff }\Rightarrow \begin{matrix}\forall x_1,x_2\in X, x_1\neq x_2 \\\exists U_1,U_2\in{\Large\tau}\text{ s.t. }x_1\in U_1, x_2\in U_2\\U_1\cap U_2=\emptyset\end{matrix}$$
### Theorems
* Every finite point set in a Hausdorff space $X$ is closed.
* For any given Hausdorff space $X$, a sequence of points of $X$ converges to at most one point of $X$.
* Every [[Relations#Strict Order|strictly ordered]] (simply ordered) set is a Hausdorff space in the order topology.
* The Product of two Hausdorff spaces is a Hausdorff space
* A subspace of a Hausdorff space is a Hausdorff space.
## $T_1$ Axiom
Weaker version of Hausdorff, which states that finite point sets be closed.
# Continuous Functions
## Definition
Let $X$ and $Y$ be topological spaces. A function $f: X\to Y$ is said to be continuous if for each open subset $V$ of $Y$, the set $f^{-1}(V)$ is an open subset of $X$.

Continuity then depends on both the function and the topologies specified for its domain and range. 
## Theorems for Proving Continuity
1. (Constant Functions) If $f: X\to Y$ maps all $X$ to a single point $y_0\in Y$ then $f$ is continuous.
2. (Inclusion) If $A\subset X$ is a subspace of $X$, then the [[Functions#Injective#Inclusion Maps|inclusion function]] $\iota: A\hookrightarrow X$ is continuous and homeomorphic.

### Theorem 18.1
For two topological spaces $X$ and $Y$ The following are equivalent for a continuous function $f: X\to Y$: 
1. $f$ is continuous
2. $\forall A\subseteq X\Rightarrow f(\overline{A})\subset\overline{f(A)}$ 
3. $\forall B\subseteq Y\Rightarrow f^{-1}(B)$ is closed in $X$.
4. $\forall x\in X$ and each neighborhood $V$ of $f(x)$, then there exists a neighborhood $U$ of $x$ such that $f(U)\subseteq V$.
### Proving Continuity using Basis
To prove the continuity of some range space $Y$ with basis $\mathscr{B}$, you can prove continuity by showing that every basis element is open: $$V=\bigcup_{a\in J}\mathscr{B}_\alpha\Rightarrow f^{-1}(V)=\bigcup_{a\in J}f^{-1}(\mathscr{B}_\alpha)$$
### The Discrete Topology is always Continuous
Given a function $$f: (X,{\Large\tau})\to (Y,\sigma)$$such that ${\Large\tau}$ is the discrete topology, since ${\Large\tau}$ is the power set, it will always contain the preimage of an open set of $Y$, irrelevant of the function. If instead ==**the codomain is the trivial topology**==, then it is always continuous as well.
### Proving Continuity into Products
Let $f: A\to X\times Y$ be the function we want to prove continuity on. Then it is given by: $$f(a)=(f_1(a),f_2(a))$$If we wanted to prove continuity, we could instead prove continuity of the functions: $$\begin{matrix}f_1: A\to X & & f_2: A\to Y\end{matrix}$$

### Using the Pasting Lemma
Let $X=A\cup B$, where $A$ and $B$ are closed in $X$, Let $$\begin{matrix}f: A\to Y & & g: B\to Y\end{matrix}$$be **continuous**. If $\forall x\in A\cap B, f(x)=g(x)$ then we can define a new continuous function $h(x)$ such that: $$h(x)=\begin{cases}f(x) & x\in A \\ g(x) & x\in B\end{cases}$$

### Examples
#### Example 1.0
* Consider a function $f: \mathbb{R}\to\mathbb{R}_\ell$ where $\mathbb{R}$ is the real numbers under the standard topology, and $\mathbb{R}$ is the real numbers under the lower limit topology, and $f$, the identity function $f(x)=x$. 
* This function would then not be continuous since the inverse image of $[a,b)$ in the lower limit topology $\mathbb{R}_\ell$ is not open in $\mathbb{R}$.
* Alternatively consider a similar identity function $g: \mathbb{R}_\ell\to\mathbb{R}$. This, function would be continuous since every $(a,b)$ in the range space $\mathbb{R}$ is present in $\mathbb{R}_\ell$.
## Homeomorphisms
Let $X, Y$ be topological spaces, and $f: X\to Y$ be a [[Functions#Bijective|bijection]] meaning that there exists also a function $f^{-1}: Y\to X$. If both $f$ and $f^{-1}$ are continuous, then $f$ is a homeomorphism. This means any property of $X$ called a ==**topological property of $X$**==, is held by $Y$. (Left off at page 106, pdf 121)

# Metric Spaces
The definition of a metric space is a set $X$ equipped with a metric $d$ for measuring distance, usually denoted as an ordered pair $(X, d)$. The metric $d: X\times X\to\mathbb{R}$ has 3 defining properties which apply $\forall x,y,z\in X$:
1. $d(x,y)=d(y,x)$
2. $d(x,y)\geq 0$ and $d(x,y)=0\Rightarrow x=y$
3. $d(x,y) + d(y,z) \geq d(x,z)$
Where the number $d(x,y)$ is usually called the distance between $x$ and $y$.
### Epsilon Balls
We can form a ball given a metric $d$ using epsilon balls. Consider the set given by $\epsilon > 0$: $$B_d(x,\epsilon)=\{y|d(x,y)<\epsilon\}$$
Which would be the $\epsilon$-balls centered at $x$, sometimes denoted as $B(x,\epsilon)$ when no confusion will arise from omitting the metric.
## Metric Topology
If $d$ is a metric on the set $X$, then the collection of all $\epsilon$-balls $B(x,\epsilon)$, for $x\in X$ and $\epsilon>0$, forms a basis for a topology on $X$, called the metric topology induced by $d$. We can also say that:

A set $U$ is open in the metric topology induced by $d$ if for each $y\in U$, there is a $\delta > 0$ such that $B_d(y,\delta)\subset U$.
## Metrizability
A set is said to be ==**metrizable**== is there exists a metric $d$ which induces the topology of $X$.
## Boundedness
Let $(X, d)$ be a metric space. $A\subseteq X$ is said to be bounded if there exists $M$ such that $\forall a_1,a_2\in A$ $$d(a_1,a_2)\leq M$$The diameter of $A$ is then defined with the [[Real Analysis#Definition of the Supremum|supremum]] $$\text{diam}(A)=\text{sup}(\{d(a_1,a_2)|a_1,a_2\in A\})$$
Considering boundedness depends on a metric, it is not a topological property.
## Metrics
### Standard Metric of the Real Number Line
The standard metric on $\mathbb{R}$ is $d(x, y)=|y-x|$. It has the property that: $$(a,b)=B(x,\epsilon)$$Meaning that it forms the standard topology on $\mathbb{R}$.
### Standard Bounded Metric of $d$
Given a metric space $(X,d)$, let $\overline{d}=\text{min}(d(x,y),1)$. Then $d$ and $\overline{d}$ induce the same topology since
1. Case 1: When $d(x,y) < 1$ then $d=\overline{d}$.
2. Case 2: When $d(x,y) = 1$ then $1=d=\overline{d}$
3. Case 3: When $d(x,y)>1$ then $1<d(x,y)<\epsilon$ and $1=\overline{d}(x,y)<\epsilon$ meaning that $$1=\overline{d}(x,y)<d(x,y)<\epsilon$$and therefore share the same collection of $\epsilon$-balls, since they are both lesser than epsilon.

## Metrics which give the Product Topology
The following metrics give the same topologies as the product topology.
### Euclidean metric on $\mathbb{R}^n$
We can define the Euclidean metric, by grabbing a norm of the space: $||x||=(\sum_{i=1}^{n}{x_i^2})^{\frac{1}{2}}$, and then we can define the metric as: $$d(x,y)=||x-y||$$
### Square metric on $\mathbb{R}^n$
We define the square metric, sometimes referred to as the manhattan metric due to how it looks like the roads in the city of manhattan, $\rho$ as: $$\rho(x,y)=\text{max}(|x_1-y_1|,...,|x_n-y_n|)$$
## The Uniform Metric
We can generalize the square metric by grabbing the supremum instead of the maximum: $$\overline{\rho}(x,y)=\text{sup}(|x_n-y_n|)$$
