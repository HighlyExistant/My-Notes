# Definition
A Category is a collection of ==**objects**== and ==**morphisms**== such that 
1. each object has an identity morphism
2. composition makes sense for morphisms.
	* Composition of morphisms is ==**associative**==
## Objects
In principle it can be anything, usually a number or a set or another mathematical structure.
## Morphisms
These are transformations done to the objects, to transform them into other objects. Such as transforming $A\to B$.
