# Ganancia Economica
1. Winnings = Total Income - Total Cost
2. Costo Total = wL + iK + rT + $\pi$E
3. wL= salario $\cdot$ unidades de mano de obra
4. iK = interes $\cdot$ unidades de capital
5. rT = renta $\cdot$ unidades de recursos naturales o tierra
6. $\pi$E = ganancia normal $\cdot$ Factor empresarial
# Relationships

3. Costo total promedio = $\frac{\text{C}(Q)}{Q}$
4. Competencia perfecta $\Rightarrow \text{CTP}=\text{CM}$
## Largo Plazo
Let $P_{LP}$ be the price over the long term and $P_I$ be the initial price, then 
* If $P_{LP}> P_I$ then there is an economic loss
* If $P_{LP}< P_I$ then there is an economic gain
