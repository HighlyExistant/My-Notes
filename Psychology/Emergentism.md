* ==**Emergence**==: Properties that emerge from a system that aren't present in its individual parts.
These are typically brought about by views in reductionism, where the whole can be explained by its constituent parts, *a system is nothing but the sum of its parts*. This view of the system is considered very simplistic. A better view is that the system contains features that none of the parts have, as the definition above describes.
# Weak Emergence
Given a set of rules $X$, and emergent properties derived from the composition of those rules $Y$, there is an asymmetrical relation wherein all emergent properties $Y$ can be expressed solely by those rules in $X$.
# Strong Emergence
Given a set of rules $X$, and emergent properties derived from the composition of those rules $Y$, there is an asymmetrical relation wherein all emergent properties $Y$ cannot be expressed solely by those rules in $X$, instead some of $Y$ explains $X$.

## Model for General Reductions
### Step 1
* Let $B$ be the domain of properties serving as the reduction base
* Let $E$ be a reducible property defined using properties in $B$.
* Let $E\overset{\text{def}}{=}P \in B$ s.t. $C_1, ..., C_{n}^{16}$ cause $P$ to be instantiated. and $P$ causes $F_1,...,F_m$ to be instantiated. 
This implies that for every $E$, then $P$ is also realized.
### Step 2
* Find realizers of $E$ in $B$.
* If desired, find instances of the realizing property $P$ in virtue of which $E$ is instantiated on this occasion in this system.
### Step 3
* Find a theory at the level of $B$ that explains how realizers of $E$ perform causal tasks that is constitutive of $E$ (the causal role of Step 1). This could also explain other relations in which $E$ plays a role.
